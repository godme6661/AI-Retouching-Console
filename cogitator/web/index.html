快捷键与用法

  

    

      
\（按住）临时看原图，松开回成品

      
Ctrl+Z撤销上一批修改

      
Ctrl+Y / Ctrl+Shift+Z重做

      
Ctrl+S打开导出对话框

      
Ctrl+V粘贴剪贴板里的图片（作为新图层或新工程）

      
拖入文件直接拖图片进窗口；拖动时画布会高亮落点

      
Enter / Shift+Enter在对话框里：发送 / 换行

      
?打开本帮助

      
Esc关闭当前对话框

    

    

      顶栏「适应」按钮可在 适应窗口 → 预览 100% → 预览 200% 之间切换。
      注意：预览是按显示尺寸渲染的下采样图（例如 6000px 的照片预览只有约 1400px），
      所以「预览 100%」是按预览像素显示，观感相当于把成片缩小到该尺寸观看。
    

    

      要按输出像素判断锐化与噪点，请点顶栏的 「输出像素」：它会用全分辨率渲染当前视口
      （首次约数秒，之后按修订号缓存，拖动只做裁剪、很快），拖动画面即可平移查看 1:1 细节。
      该模式下不做原图对比（基准尺寸不同）。
    

    

      图层步骤超过 8 步时会自动折叠中间部分（点折叠行展开）；素材库会标出每个素材
      已用于哪些图层，点素材行可直接跳到对应图层。
    

    
右侧面板左边缘可拖动改宽度；窗口较窄时会自动变成上下布局。
