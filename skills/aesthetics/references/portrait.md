# 人像：像本人 + 状态更好

## 第一原则：皮肤要有纹理
- 观众判断"修过没修过"几乎只看一件事：**皮肤还有没有毛孔与细纹**。
- 因此：不要用 `blur` 大面积磨皮，不要 `denoise` 拉到 60 以上。
  正确路径是 `clarity` 轻微负值（-8~-15）柔化 + 分区 HSL 调肤色 + 轻微降噪（10~25）。
- 反例：脸像塑料、纹理"消失"、轮廓出现灰边——这是最典型的新手痕迹。

## 分区处理肤色（人脸不是一张均匀色卡）
| 区域 | 常见问题 | 处理 |
| --- | --- | --- |
| 面部 | 偏红、偏黄、发灰 | `hsl` orange：饱和 -5~-12、明度 +4~+10、色相 ±3 以内 |
| 额头/鼻头 | 油光、过曝 | `highlights` -10~-25；局部压暗 |
| 手 | 比脸更红更暗 | `hsl` red 饱和 -10~-20、`shadows` 局部提亮 |
| 耳朵/脖子 | 红、与脸色不一致 | 同上；耳尖过红时明显降红带饱和 |
| 眼袋/法令纹 | 阴影过重 | 局部提亮（蒙版 + `shadows`），别磨皮 |

**红手指、红耳朵是最容易暴露修图的细节**，比脸更值得检查。

## 眼睛
- 眼神光：保留并轻微增强，眼睛立刻"活"。
- 眼白：可提亮，但**不要推到过曝发蓝**（新手最显眼的错误之一）。
- 虹膜：适度补饱和（`hsl` blue/green 该色带饱和 +6~+12），别做荧光色。
- 睫毛与眉毛：保持清晰，不要一起被降噪糊掉。

## 牙齿与唇
- 牙齿：发黄就降黄带饱和（`hsl` yellow 饱和 -10~-20）+ 轻微提亮；不要漂白到纯白。
- 唇：红色带色相可微调（偏冷/偏暖），饱和度提升控制在 +10 以内。

## 背景分离（提升"专业感"最快的一招）
三种手段，按代价从低到高：
1. **压暗背景**（图层蒙版 / 暗角）——最自然。
2. **降背景饱和**——让肤色成为全场唯一暖色。
3. **抠图换背景**（`remove_bg`）——最彻底，但边缘（发丝、半透明纱）最容易露馅，要检查羽化与边缘色边。

注意：抠图后主体边缘常残留原背景的颜色（色边），需要 `mask_brush` 收缩 1~2px 或轻微降低边缘饱和。

## 身材与脸型：分寸问题
- 修图可以：矫正姿态造成的局部夸张、清理临时瑕疵（痘、碎发、灰尘）。
- 修图不该：改变骨骼结构与身份特征（大改脸型、拉长身体、改身材比例）。
  一旦被看出来，照片就从"好照片"变成"假照片"。
- 本工具的 `transform_layer` 只能整体缩放/旋转，**没有液化**——这是刻意的限制。

## 具体工序建议
1. 校正：白平衡（以脸部与白衣/白墙为准）、曝光、水平。
2. 构图：裁切（先看四边四角）、头顶空间、视线留白。
3. 光比：`highlights` 压油光、`shadows` 提眼窝与暗侧、`contrast` 定基调。
4. 肤色：分区 HSL（面/手/耳分别处理）。
5. 质感：`clarity` 轻微负值，`sharpen` 只对眼睛与发丝（用蒙版）或整体低强度 15~25。
6. 氛围：`split_tone`（高光暖 + 阴影冷）、`vignette` 轻微、`grain` 视风格。
7. 自检：放大看皮肤纹理、手、耳朵；缩小看整体；检查牙齿是否过白、眼白是否过曝。

## 本工具的对应算子
`remove_bg`（抠图换底）、`hsl`（面/手/耳分区）、`highlights`/`shadows`（光比与提亮）、
`clarity`/`sharpen`/`denoise`（质感三件套）、`split_tone`、`vignette`、`grain`、
`mask_brush`（局部修补）、`crop_ratio`、`apply_style`（`creamy-portrait` 是安全起点）。

## 检查点
皮肤还有纹理吗？手指耳朵是否发红？眼神光在吗？眼白过曝了吗？
牙齿是否假白？背景是否安静？这个人还像本人吗？
