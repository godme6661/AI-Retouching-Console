# 色彩：先准，再美

## 校正与分级是两件事（顺序不能反）
- **色彩校正**：修正白平衡偏差、去色偏、把中性物还原成中性。目标只有一个——"准确"。
- **色彩分级**：在准确的基础上，为情绪服务地偏移色彩。目标只有一个——"感觉"。
- 顺序：校正 → 分级。跳过校正直接加风格，等于在歪地基上刷漆，越刷越脏。

## 色轮与和谐
- **互补**（色轮相对）：蓝橙、红绿、黄紫。互补制造张力，但**比例要一大一小**：
  主色占大面积、互补色作点缀（如 90% 蓝背景 + 10% 橙肤色）。五五开就是互相抵消。
- **类似**（相邻）：黄-黄绿-绿、蓝-青-蓝紫。和谐平静，适合清淡题材；缺点是容易"平"。
- **三角**：三个均匀分布的色相，丰富但难控制，一般不要主动制造。
- 判断现有画面：数一数主色有几个。超过 3 个且都饱和，先降饱和统一再加风格。

## 白平衡
- 先找中性参照物：白墙、灰路、白衣、白盘。偏了就先掰回来。
- 方向速查：整体偏黄 → 降温（色温负）或减黄；偏蓝 → 升温；偏绿 → 加品红（色调正）；偏品红 → 加绿。
- 肤色判色温：健康肤色不是纯白，偏红黄是正常的；**不要把脸色调成中性灰**，那是"失血感"。
- 混合光源（窗光 + 钨丝灯）无法全局修正，此时只能局部处理或干脆转黑白。

## 分区 HSL：替代全局饱和度
全局拉饱和是最容易毁图的动作：蓝天先过曝、绿叶先发荧光、人脸先变橙。
正确做法是分色带处理：
| 对象 | 常用手法 |
| --- | --- |
| 天空 | 蓝色带：降明度（-8~-15）比加饱和更自然；偏紫就色相往青推 |
| 绿植 | 绿色带：向黄统一（-8~-15）得温暖；向青统一（+8~+15）得清冷；降饱和 -10~-25 去"塑料绿" |
| 肤色 | 橙色带：降饱和 -5~-12、色相 ±3 以内、明度 +4~+10 |
| 夕阳/暖光 | 橙红色带：保饱和，明度别压，压了就没温度 |
| 阴影 | 蓝色带：轻微降明度可以加深"蓝调时刻"的氛围 |

## 肤色红线（越界立刻显假）
- 健康肤色的色相大致落在红-橙区间；**橙色带色相偏移超过 ±8°** 就会改变"人种观感"。
- 饱和度上限：普通肤色不宜超过 70%；already 高饱和的脸再提就是"高原红"。
- 明度：提亮脸部是常规操作，但一次超过 +15 容易失去立体、变成"面饼"。
- 手、耳、脚、脖子往往比脸更红更暗：分区处理时单独照顾，否则"红手指"非常显眼。

## 分离色调（split tone）：最安全的电影感
- 万能公式：**高光暖 + 阴影冷**（如高光 38~50 / 阴影 195~215）。
- 两边都暖 → 发脏发旧；两边都冷 → 生硬冰冷。除非刻意要这两种味道，否则不要。
- 强度纪律：双方各 8~22 已经很明显；超过 30 就是"调色过火"的典型外观。
- 高光加点暖可以救回"数码冷感"；阴影加青可以立刻有电影味。

## 饱和 vs 自然饱和
- `saturation` 等比提升全部色彩，最先失控的是已经饱和的区域（天空、红花、荧光衣）。
- `vibrance` 只补欠饱和区域，兼顾肤色保护。**想更鲜艳，先动 vibrance**。
- 整体降饱和（-15~-30）+ 轻微提 vibrance = 高级灰调（莫兰迪方向）。

## 黑白
- 黑白不是"没颜色"，是**用明度关系说话**：黑的要沉、白的要亮、中间调要有层次。
- 转换后原彩色关系丢失，因此要靠对比、清晰度、颗粒补结构。
- 轻微分离色调（高光暖 +4~+8、阴影冷 +4）可以做出暖调银盐/硒调的感觉。
- 彩色原片里靠颜色区分的主体，转黑白后可能糊成一团：此时改裁切或调明度。

## 常见的色彩失误
过饱和（尤其蓝天绿叶）、跨色带污染（改了绿把黄也改了）、互补色五五开、
色温与情绪不匹配（温暖场景调冷）、把阴影压成纯黑丢层次、渐变区拉出**色阶断层**。

## 本工具的对应算子
`temperature`（冷暖）、`tint`（品红-绿）、`levels`（黑白场与伽马）、`curve`（分通道曲线）、
`hsl`（分区色相/饱和/明度）、`split_tone`（分离色调）、`saturation`、`vibrance`、
`auto_enhance`（自动白平衡 + 自动色阶的安全起点）、`grayscale`、`sepia`、`hue`（整体色相旋转，慎用）。

## 检查点
中性物是否中性？肤色是否可信？蓝天绿叶是否过饱和？阴影里还有没有层次？
高光与阴影的色偏是否互相打架？
