# 风格配方：起点，不是终点

## 使用纪律
1. **先校正再套风格**（白平衡、曝光、水平没修就套风格 = 在歪地基上刷漆）。
2. **一次只套一个风格**。叠加两个风格会得到"脏灰"——那是两种色偏互相抵消的结果。
3. **强度首轮 80%**，看完效果再决定是否加到 100~120。150 只用于确有意图的氛围片。
4. 套用后**必须针对这张照片微调至少一处**，通常是：
   - 肤色（偏橙就压 `split_tone` 的高光饱和或橙带饱和）
   - 高光（风格常带 `highlights` 负值，过曝的片子要再压）
   - 主体分离（背景太亮就加暗角或压背景）
   配方是通用解，不是这张照片的解。

## 配方与题材的匹配表
| 配方 id | 名称 | 适合 | 不要用于 |
| --- | --- | --- | --- |
| jp-airy | 日系空气感 | 日常、静物、阴天人像、咖啡店 | 夜景、强对比建筑 |
| film-warm | 胶片暖调 | 人像、街拍、旅行 | 商业白底产品图 |
| cinematic | 电影青橙 | 街拍、城市、夜幕人像 | 肤色占比极大的特写（脸会发橙） |
| moody-dark | 暗调氛围 | 静物、雨天、建筑、情绪人像 | 明亮日系原片（会互相抵消） |
| neon-night | 夜景霓虹 | 城市夜景、赛博感街拍 | 白天照片 |
| creamy-portrait | 奶油人像 | 写真、亲子、柔光人像 | 硬光男性肖像（会失去力量） |
| clear-landscape | 通透风光 | 风光、旅拍、雪山草原 | 雾天（会把雾压掉） |
| arch-cool | 建筑冷峻 | 建筑、室内、城市几何 | 暖调人文场景 |
| food-warm | 美食暖香 | 美食、咖啡、产品 | 需要中性色的白色瓷器特写 |
| morandi | 莫兰迪低饱和 | 静物、穿搭、室内、花艺 | 需要冲击力的新闻/运动 |
| vintage-fade | 复古褪色 | 日常、怀旧、旅行 | 需要通透感的风光 |
| bw-hard | 黑白硬调 | 纪实、建筑、质感、纹理 | 靠颜色区分主体的画面 |
| bw-soft | 黑白柔调 | 人像、雨天、安静纪实 | 需要力量感的硬题材 |

## 匹配逻辑（怎么选）
1. **先看题材** → 表里第一列。
2. **再看光线条件**：硬光高对比 → 选能压高光的（cinematic / clear-landscape）；
   软光低对比 → 选能给层次的（film-warm / creamy-portrait）。
3. **再看用途**：社交分享可强一点；打印与档案要更克制（强度 60~80）。
4. **最后看肤色占比**：肤色是主角时，优先 creamy-portrait / film-warm；
   肤色只是环境的一部分时，cinematic / moody-dark 才安全。

## 套用之后（三个必查）
1. 皮肤色调是否还像人？（尤其 cinematic 与 vintage-fade）
2. 高光是否被风格带得更死？（风格里的 `highlights` 负值不够时手动补）
3. 色彩是否互相打架？（风格里的 `split_tone` + 画面原有互补色叠加后可能过火）

## 手动复原的替代
用户说"风格换一个"时：先 `remove_op` 逐条撤掉上一个风格的步骤（它们都在管线里、看得见），
再套新的。不要直接叠加第二个风格。

## 本工具对应
套用：`apply_style`（参数 `style` 与 `strength`），或用界面「图层」页的风格选择器。
配方文件：`cogitator/styles.json`（每个算子都可通过注册表校验，可自行增删配方）。
