# 看图诊断：先分类，再逐项过

## 第一步：分类（决定评价权重）
| 题材 | 最看重 | 可以放宽 |
| --- | --- | --- |
| 人像/写真 | 肤色可信、眼神、皮肤纹理、光比 | 背景细节、边缘锐度 |
| 风光 | 动态范围、层次、干净的颜色 | 局部细节、噪点 |
| 静物/美食 | 白平衡、质感、高光成形 | 背景复杂度（可裁/可换） |
| 街拍/纪实 | 瞬间、主体明确、真实性 | 完美曝光、锐度 |
| 夜景 | 高光成形、暗部可读、噪声控制 | 全局对比、鲜艳度 |
| 建筑 | 垂直线、几何、清晰度 | 天空颜色 |
| 翻拍/文档 | 平整、中性、文字可读 | 美感 |

## 第二步：逐项检查（每项给"看到 → 怎么调"）
1. **曝光**：整体偏亮/偏暗？→ `exposure` ±0.1~0.4EV。
2. **直方图两端**：右侧贴墙（过曝）→ `highlights`/`whites` 压；左侧堆积（死黑）→ `shadows`/`blacks` 提。
3. **白平衡**：中性物是否偏色？→ `temperature`/`tint`，或用 `auto_enhance` 起步。
4. **对比与层次**：中间调是否发灰？→ `contrast` + `clarity`；是否过硬？→ 降对比、提暗部。
5. **光比**：暗部与亮部差距是否过大/过小？→ `shadows`/`highlights` 调整光比。
6. **水平与透视**：地平线/柱子是否斜？→ `straighten`。
7. **构图**：主体是否明确？四边四角是否有杂物？视线方向是否留白？→ `crop`/`crop_ratio`/`canvas`。
8. **色彩关系**：主色几个？是否互补色五五开？是否某色过饱和？→ `hsl` 分区 + `vibrance`。
9. **肤色**（有人物时）：是否偏红/偏橙/偏黄？手耳与脸是否一致？→ `hsl` orange/red。
10. **质感**：噪声、锐度、是否已有光晕？→ `denoise`/`sharpen`/`clarity`（注意别过头）。
11. **主体分离**：背景是否抢视线？→ 压背景、暗角、抠图换底。
12. **风格一致性**：色调是否统一？有没有半张图是暖的半张是冷的？→ `split_tone`/`hsl` 统一。

## 第三步：分级输出问题
- **严重**（必须处理）：过曝成片、死黑成片、明显色偏、地平线歪、主体不明确。
- **可见**（值得处理）：肤色偏色、高光缺细节、背景抢戏、局部过饱和。
- **微调**（锦上添花）：暗角、颗粒、轻微分离色调。

写点评或提建议时按这个分级组织，用户才知道先改哪个。

## 第四步：只在必要时才加载参考（渐进式披露）
| 诊断结果 | 加载哪份参考 |
| --- | --- |
| 构图问题（主体不明确、杂乱、裁切纠结） | `composition` |
| 色彩/白平衡/肤色问题 | `color`（人像再看 `portrait`） |
| 光比、光影结构、逆光问题 | `light` |
| 风光类（层次、天空、绿植、去灰） | `landscape` |
| 静物/美食类 | `stilllife` |
| 街拍/纪实类 | `street` |
| 需要定风格或风格不对味 | `styles` |
| 不确定从哪下手 | `workflow` |
| 想避免显假的处理 | `avoid` |

一次最多加载 2 份；常识能判断的不要加载（省 token 也更快）。

## 好照片的四个共同点（最后用它复核）
1. **有一个明确的主体**，且第一眼就能找到。
2. **影调有落点**：有真正的黑、有真正的白、中间调有层次。
3. **颜色不打架**：主色明确，互补色只作点缀。
4. **可信**：看不出修复痕迹，肤色、质感、边缘都经得起放大。
