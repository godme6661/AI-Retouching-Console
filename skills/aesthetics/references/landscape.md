# 风光与建筑：层次与层次感

## 动态范围：先救高光，再提暗部
1. `highlights` -20~-40 先把天空/水面拉回细节（这是风光最常见的第一步）。
2. `shadows` +10~+25 提暗部，但**不要超过 +30**：过了会发灰、出现"HDR 感"。
3. `whites` 与 `blacks` 收两端：白场不切、黑场不糊，让直方图两端有落点。
4. `contrast` 最后定基调：风光通常需要比人像更强的对比（+10~+20）。

## 天空
- 让天空更蓝的正确做法是**降明度**（`hsl` blue 明度 -8~-15），而不是猛加饱和。
  加饱和先出现的是色阶断层与"塑料蓝天"。
- 天空发白/发灰：降蓝带明度 + 提对比 + 轻微降绿带饱和（大气雾霾常偏黄绿）。
- 日出日落的暖色（橙红带）：保住饱和、别压明度，压了就没温度。

## 绿植
- 统一色相是"看起来专业"的关键：一片林子里同时有黄绿和蓝绿会显脏。
  统一到暖（绿色带 hue -8~-15）或统一到冷（+8~+15），不要来回。
- 降饱和 -10~-25 去掉"塑料绿"，风光照片里绿叶过于鲜艳是最常见的过度处理。
- 需要春意时提黄绿明度，需要幽深时降绿色明度。

## 层次与纵深
- 三层结构：前景（引导/遮挡）、中景（主体）、远景（环境）。
- **空气透视**：远景轻微降饱和 + 提亮（或压暗，取决于氛围）能立刻拉开距离感。
  用图层 + 蒙版实现，比全局滑杆自然得多。
- 前景压暗可以形成自然的框，把视线推向中景主体。

## 去灰与"通透"
- `auto_enhance` 55~70 是最安全的起点（自动白平衡 + 自动色阶）。
- 去灰本质是**让中间调有对比**：`clarity` +8~+20 有效，超过 +25 边缘会出现灰白描边。
- `vibrance` +12~+25 比 `saturation` 安全；风光最容易过饱和的对象是天空与草地。

## 透视与几何（建筑）
- 垂直线必须竖直，这是建筑照片的底线；轻微倾斜靠 `rotate`，大幅倾斜需要透视矫正（本工具不做）。
- 广角边缘的拉伸不要把主体放在最边缘。
- 对称构图（正对建筑、倒影）可以居中，此时对称就是内容。
- `clarity` 对建筑很有效（+15~+25），但要注意天空与墙面交界处的光晕。

## HDR 感的成因（要主动避免）
- 全局对比过低 + 中间调过亮 + 暗部无黑场 = 一眼假的 HDR。
- 修正：把 `blacks` 压回一点、把高光留出亮度、保留一处纯黑与一处纯白（画面需要"落点"）。

## 水与倒影
- 倒影通常比实景暗且饱和度低；轻微提倒影的亮度、别让倒影比实景更抢眼。
- 长曝的丝滑水面靠拍摄，后期只能轻微柔化（`blur` 很小值 + 蒙版），别大范围糊。

## 本工具的对应算子
`highlights`、`shadows`、`whites`、`blacks`、`contrast`、`clarity`、`vibrance`、
`hsl`（蓝/绿/橙红分区）、`auto_enhance`、`levels`、`curve`、`straighten`、`crop_ratio`、
`vignette`、`apply_style`（`clear-landscape` 与 `arch-cool` 是安全起点）、`add_layer` + `mask_brush`（分区域处理）。

## 检查点
高光里还有细节吗？暗部是否发灰？天空是否过饱和或有断层？绿植色相是否统一？
地平线是否水平？是否有"一眼 HDR"的低对比感？画面有没有一处真正的黑与一处真正的白？
