# 光：先读光，再修图

## 光质：软硬由"相对光源尺寸"决定
- 光源相对主体越大越近 → 越软：阴影边缘模糊、过渡长、皮肤好看。
- 越小越远（裸灯、正午太阳、闪光灯直射）→ 越硬：阴影边缘锐利、对比强、有力量也更容易出丑。
- 修图能做的：软光救不了硬光造成的结构性问题，但硬光下可以**提暗部减光比**来缓和。

## 光向：方向决定情绪
| 光向 | 效果 | 注意 |
| --- | --- | --- |
| 正面平光 | 干净、商业、无立体 | 容易"证件照"，靠背景与色彩补 |
| 45° 侧前（最常用） | 有立体又自然 | 鼻影方向要好看 |
| 90° 侧光 | 戏剧、结构强 | 光比过大时暗侧要补 |
| 逆光 | 轮廓 + 氛围，通透 | 主体暗部需补光，否则黑脸 |
| 顶光（正午） | 眼窝与鼻下重影 | 提暗部 + 压高光有救 |
| 底光 | 反常、恐怖感 | 一般不用 |

## 光比 = 主光与辅光的亮度差
- 2:1 柔和、亲和、商业；4:1 立体、有质感；8:1 以上硬朗、戏剧、偏男性化。
- 修图能改光比：`shadows` 提暗部 = 缩小光比；`highlights` 压高光 + 加对比 = 增大光比。

## 人像五大 pattern（用来判断光位，也用来解释"为什么好看"）
- **蝴蝶光（butterfly）**：光源在正前偏上，鼻下出现小而对称的影。颧骨高、下巴线清楚，适合女性与美妆。
- **环路光（loop）**：光源偏一侧约 30~45°，鼻影在颊上形成小圈而不接唇线。最百搭，最不容易出错。
- **伦勃朗光（Rembrandt）**：光源更高更侧，颊部出现三角形亮块（被鼻影与颧骨影围出）。有画意、有戏剧性。
- **分割光（split）**：光源 90° 侧，脸一半亮一半暗。强烈、有性格，光比大。
- **宽面/窄面**：面向镜头那一侧被照亮叫宽面（脸显宽），反之为窄面（显瘦）。拍人像时先看这个。

## 轮廓光与眼神光（两张"廉价提升专业感"的牌）
- **轮廓光/发丝光**：来自侧后方的光勾出主体边缘，把主体从背景里"摘"出来。
  修图替代方案：把背景压暗降饱和、给主体边缘加一层轻微提亮（靠蒙版 + 曲线/暗角反用）。
- **眼神光**：两只眼睛都要有；缺一只会显得呆滞。后期可以轻微提亮眼神光位置，
  但**不要**把眼白整体提亮到发蓝发光——那是典型的新手痕迹。

## 识别常见光线问题 → 对应动作
| 看到 | 原因 | 修图动作 |
| --- | --- | --- |
| 眼窝发黑 | 顶光 | 局部提暗部（蒙版 + `shadows`）、轻微降对比 |
| 鼻下双影/重影 | 正面硬光 + 补光角度错 | 提暗部、把重影处压暗弱化 |
| 脸半边死黑 | 光比过大 | `shadows` +20~40，或局部提亮暗侧 |
| 脸平无立体 | 平光 | 加对比 + 提高光/压暗轮廓（`clarity` + `split_tone` 高光暖） |
| 逆光主体发灰 | 眩光/反差丢失 | 提对比 + `levels` 黑场收紧 + `hsl` 肤色提饱和 |
| 背景比主体亮 | 背景抢视线 | 背景压暗（图层 + 蒙版）、主体提亮、暗角收拢 |
| 高光糊成一片 | 过曝 | `highlights` -20~-45，`whites` 微降；死了就救不回，如实说明 |

## 时间与色温
- 黄金时刻（日出后/日落前约 1 小时）：暖、低角度、影子长，人物与风光都吃这套光。
- 蓝调时刻（日落后约 20~40 分钟）：天空冷蓝、城市灯亮；白平衡偏冷、暗部要提，别压死。
- 正午：硬光 + 高对比，优先找阴影或透光（树影、窗光）。

## 本工具的对应算子
`exposure`、`highlights`、`shadows`、`whites`、`blacks`、`contrast`、`curve`（精确控层次）、
`clarity`（局部对比，给体积）、`hsl`（色带明度可做分区提亮）、`split_tone`（色偏塑光感）、
`vignette`（收拢视线）、`mask_brush` + 局部算子（真正的局部提亮/压暗）。

## 检查点
光向是哪一种？光比大不大？主体是否从背景里"出来"了？眼神光在不在？
高光是否保住细节？暗部里还有没有层次（不要压成纯黑）？
