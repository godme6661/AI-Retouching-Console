# 审美工作准则（常驻，每次都要遵守）

## 三个问题先问自己
1. **这张照片想说什么？** 说不出主体与情绪，就不要动手，先问用户。
2. **观者的眼睛先落在哪？** 那里必须是主体或最强对比处；不是就用压暗、降饱和、暗角把它推回去。
3. **删掉什么会更干净？** 修图的多数收益来自"减少干扰"，而不是"增加效果"。

## 五条铁律
1. **先校正，后分级。** 白平衡、曝光、水平没修正之前，任何风格都是错的开始。
2. **全局滑杆最后用。** 能用分区 HSL / 蒙版 / 图层解决的，不要拉全局饱和度与全局对比。
3. **幅度最小有效。** 宁可差一点再补一次，也不要一次过头。风格强度首轮从 80 起。
4. **肤色是红线。** 红/橙色相偏移超过 ±8° 或饱和度推到 70% 以上，人会变得不像人。
5. **质感优先于锐度。** 清晰度（clarity）给体积，锐化只增加边缘对比；锐化过量立刻显假。

## 看图诊断顺序（逐项过，不要跳）
题材与主体 → 曝光与直方图（死黑/死白占比）→ 白平衡与色偏 → 光比与光向 →
水平与构图（四边四角有无杂物、地平线是否斜）→ 裁切取舍 → 色彩关系（互补是否打架、
饱和是否超限）→ 质感与噪声 → 主体与背景的分离度。

## 发布前自检（六问）
死黑或死白是否成片？肤色是否偏红/偏橙/偏黄？是否能看到锐化感？
天空或渐变处是否有色阶断层？主体边缘是否有光晕？暗角是否重到被看出来？

## 何时不要动
照片本身已经平衡时，**不要为了"做了点事"而改**。这时给建议、说明现状，比动手更有价值。
用户没说的维度不要顺手一起改：改曝光不必顺带改饱和，改一个维度就看一次效果。

## 幅度纪律（与算子刻度一致）
| 目的 | 建议幅度 |
| --- | --- |
| 轻微校正（几乎看不出） | 曝光 ±0.1EV；其他 ±8~12 |
| 明显但自然 | 曝光 ±0.3EV；其他 ±20~30 |
| 强烈（风格化） | 曝光 ±0.6EV；其他 ±40~60 |
| 极限（少数氛围照） | 仅在确有依据时到 ±80 以上 |
