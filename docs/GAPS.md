## 明细

### G1. 对话流里还不能调用外部引擎
- **现状：** 外部引擎（photocraft 的 858 条命令）已可通过 HTTP 与 MCP 调用，产物作为新图层回到工程；
  但**对话里的 AI 还不能自己发起**这种调用。
- **为什么还没做：** 本项目的管线语义是"可重放"——同一份配方在任何机器上重放出同一张图。
  外部引擎调用不满足这个前提，所以要新增一类显式的**非重放算子**（比照现有的画布类结构算子），
  并想清楚：它进不进历史、撤销粒度怎么算、导出时是否重跑。**没想清楚就不做**，否则会破坏
  项目最核心的可复现性。
- **影响：** 用户得手动通过 API / MCP 触发引擎命令，或等这一条补上。

### G2. 没有 PSD 导入 / 导出
- **现状：** 支持 PNG/JPG/WEBP/BMP/TIF/GIF + 18 种 RAW 扩展名；**没有 PSD/PSB**。
- **两条路：** 自己实现（PSD 是复杂的层级格式，含图层、蒙版、文字、智能对象）或
  **委派给外部引擎**（已实现通道，`/api/engine/run` 可以调 photocraft 的 PSD 相关命令）。
- **注意：** 外部引擎自己把「PSD 保真」列为它的头号缺口（blocks beta），所以别承诺无损往返。

### G4. 预览不是输出像素
- **现状：** 预览按显示尺寸渲染（默认最长边 1400px），像素单位参数按比例同步缩放；
  与"全分辨率渲染再缩小"在数值上等价，因此**预览对观感是可信的**，但**不能**用来判断
  输出像素级的锐化与噪点。
- **缓解：** 顶栏「输出像素」按视口全分辨率渲染，1:1 呈现（24MP 首次约 2.7s，之后平移走缓存约 0.01s）。
- **残留：** 该模式下不支持原图对比（基准尺寸不同，硬叠会对不齐）。

### G7. 抠图权重与许可
- **现状：** 未配置权重时自动降级 OpenCV GrabCut（边缘一般）。
- **许可：** RMBG-2.0 由 BRIA 发布、遵循其自有许可（非商业）。本仓库**不分发任何权重**。
  商业使用请向权利方申请授权，或换成许可更宽松的模型。

### G13. 内容感知填充：明确不做
- **原因：** 那属于"生成式"能力，与项目构想第 1 条（轻量、只做调色/抠图/合成）冲突，
  也会把"AI 不重绘"的定位搞模糊。需要它的场合请用外部引擎或专用工具。

## 已补齐（本轮）
- **局部调整**：渐变（线性/径向）、范围选择（亮度/饱和度/颜色）、四种蒙版都支持"只作作用域"。
  验证标准是"作用域外像素逐位不变"（实测最大差 0.0000）。详见 [DECISIONS.md](DECISIONS.md) D14。
- **跨文件批处理**：`python -m cogitator batch --in … --out … [--style|--recipe|--from-project] …`，
  顺序队列 + 进度 + `batch-report.json`；单张失败隔离；临时工程零残留（v1.5.1）。
- **出片环节**：水印（文字/图片、九宫格、透明度、字号）、边框（白/黑/拍立得）、
  导出预设（存进设置、可在界面与批处理里复用）；尺寸上限约束最终文件（v1.5.2）。
